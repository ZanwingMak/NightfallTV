# Nightfall TV · 夜幕

## 产品目标

为 Apple TV 提供好看、安静、无需账号的独立屏保播放器。白天是客厅的动态画廊，夜晚是完全黑屏的睡眠陪伴。所有功能属于同一个免费开源应用，无广告、订阅或版本分层。

## 调研结论

Apple 官方屏保覆盖航拍、照片、时钟和角色动画，体现了「大画面、慢节奏、少操作」的使用习惯。第三方放松应用常见收藏、随机播放、自然场景和睡眠定时；本应用增加卧室场景的纯黑和夜间规则。根据用户要求，自然场景改用具有免费再分发许可的真实摄影视频；声景保持本地合成，不复制 Apple 的商业航拍。

## 功能与验收

| 功能 | 实现与验收标准 |

| 屏保库 | 分类筛选、详情预览、开始播放、收藏；大字号、高对比操作按钮、遥控器焦点反馈 |
| 我的收藏 | 空态引导；单独播放；按顺序或随机轮播；避免连续重复；轮播间隔可配置 |
| 播放控制 | 点击确认键显示低亮度控制层；返回键先关闭控制层，再回到库；左右切换；播放/暂停冻结动画及轮播；控制层自动隐藏 |
| 显示自定义 | 画面亮度遮罩、动画速度、可选时钟；纯黑无条件忽略叠加元素；时钟定期漂移降低静态残影风险 |
| 声景 | 雨声、海浪、溪流、炉火、粉噪音、棕噪音；完全离线；可预听、调音量、停止；默认静音并保留其他应用音乐 |
| 睡眠定时 | 关闭或 15/30/60/90/120 分钟；最后 30 秒渐弱本应用声音；到期保持黑屏，不弹出完成提示；取消与重设可用 |
| 夜间规则 | 自定义起止小时，支持跨午夜；仅应用内生效；自动转纯黑，不强制启动应用或控制系统 |
| 启动与闲置 | 可选择启动即黑屏；库内闲置可自动播放上次场景；播放中阻止系统闲置屏保，回库/后台恢复系统行为 |
| 个人照片 | 添加/删除 HTTPS 图片地址；iPhone 遥控键盘可输入；多图轮播、间隔、柔和切换；失败显示暗色占位；限制下载大小和图片解码尺寸 |
| 设置 | 配置本地持久化；中文/英文；尊重减少动态效果；重置前确认；隐私与操作说明 |

## 视觉方向

深黑底色、蓝紫极光、暖白文字、宽松留白、圆角场景卡片。首页左侧为品牌和当前精选，右侧为大幅动态场景；屏保库使用宽屏预览卡片。动态内容适度运动，避免闪烁和突变。7 个内置自然场景均为实拍视频，预览取自原帧，素材署名在设置中可查看。最高 1080p、部分 720p，不宣称原生 4K 摄影。

## 技术与平台边界

SwiftUI + AVFoundation，最低 tvOS 17，不依赖第三方 SDK。纯黑采用独立黑色渲染路径，不运行画面动画。静音 H.264 视频以 AVPlayerLooper 循环；暂停与播放速度生效，后台暂停，减少动态效果开启后显示真实静态预览。视频播放器创建时仅预设 ambient 混音类别，不主动激活音频；只有主动选择环境音才显式激活会话。AVFoundation 可能自动激活会话，因此在静音、无音轨之外仍设置混音类别。

公开 tvOS SDK 未提供系统屏保插件入口，本应用需手动启动。RGB 全黑不能保证 LCD 背光关闭；系统音量提示、Siri、控制中心及电视自身 OSD 不受应用控制。用户退出或后台切换后，无法保持遮盖其他应用。睡眠定时只能停止本应用声音，无法停止 Apple Music、Spotify 或 AirPlay。兼容背景音乐的设计基于公开混音 API，不能替代不同播放器与真实 Apple TV 的验证。
